## Claim checks

- The six repositories above are public on the owner's GitHub account. The overview names private agent systems and describes their roles; their repository links, code, and operational details remain private.
- Latest release tags were read from each public Releases page. Exact tag links above use the corresponding visible version.
- The Bean Counter release labels its example journey synthetic and distinguishes the local product from hosted billing and independent acceptance.
- BeanFit's public README presents model/runtime output as estimates with uncertainty, not benchmark results.
- BeanFit App's public README describes an account/device companion and says automatic update alerts are planned. Its deployed-service status is owner-workspace context, not a public URL.
- Jumping Beans' frozen status and Bean Counter's ongoing-work status come from the owner. Public versions are evidence of published code, not evidence that work is active or complete.
- QA Kit documents a manifest-driven runner and JSON verdicts. Gate Kit documents a shared manifest-driven compliance gate. Their public documentation establishes tool capabilities, not adoption by every product repository.
- Private agent-system names and role descriptions in the [Agent Systems guide](AGENT-SYSTEMS.md) are summarized from owner-controlled project documentation. No private source links or operational details are included.
- The agent workflow is a proposed synthetic showcase. BeanMind documentation describes a thin task-submission reference to Agency but says there is no shared runtime state or code; the Agency runner's session-level memory configuration has not been verified. Beanstalk documents a separate supervised, offline evaluation workflow that does not execute or schedule other workflows. No automatic Agency-to-Beanstalk handoff is claimed.
- The walkthrough is not a recorded public demo. Agency executes tasks after approval; people mediate the context and evaluation handoffs shown.

## Verification limits

Public pages establish source, releases, documented demonstrations, and release-specific caveats. They do not establish user counts, commercial use, general production availability, or independent certification. Owner-confirmed context is labeled separately. A public release or shared tool does not prove that every repository uses the same checks or workflow.
