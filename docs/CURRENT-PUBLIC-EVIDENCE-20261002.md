## Checks and remaining limits

The owned static checker validates local Markdown file targets, ordinary ATX heading anchors, explicit HTML IDs and SVG XML, with repository path confinement. Offline fixtures test those mechanics. It is not a full Markdown renderer, remote-link checker, security audit or claim evaluator. Remote GitHub source/anchor targets need separate API-backed inspection; the Devpost and hosted routes are not live-browser-qualified by this refresh.

Publication safety, asset reuse/contact terms, contribution accounting and applicable historical/distributed-artifact review remain unresolved. Scores or local tests cannot waive them. The [review runbook](SHOWCASE-REVIEW-RUNBOOK.md) preserves the approval and re-audit checkpoints.
